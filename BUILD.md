# Building musl with NeoOS Shim

## Prerequisites

- neoos-kernel repository (for the shim)
- x86_64-elf cross-compiler
- Standard build tools (make, autoconf, etc.)

## Build

```bash
make KERNEL_SHIM_DIR=../neoos-kernel/third_party/shim
```

### Environment Variables

- `KERNEL_SHIM_DIR`: Path to the NeoOS shim (default: `../neoos-kernel/third_party/shim`)
- `PREFIX`: Installation prefix (default: `build-output`)

## Output

`build-output/` holds symlinks into the built `upstream/` checkout, not copies:

- `build-output/lib/` — `libc.a`, `crt1.o`, and musl's other object files
- `build-output/include/` — musl's public headers
- `build-output/include-arch-x86_64/` — x86_64-specific headers (musl's `arch/x86_64/`)
- `build-output/include-arch-generic/` — generic arch headers (musl's `arch/generic/`)
- `build-output/include-obj/` — headers generated by `configure` (musl's `obj/include/`)

All four `include*` directories must be `-isystem`'d, in that order, for
a consumer to see the right headers — see the Integration section in
`README.md`.

## Verify

Check that the shim is integrated:

```bash
grep -l "neoos" build-output/include-arch-x86_64/syscall_arch.h
# Should find neoos references in syscall_arch.h
```

## Clean

```bash
make clean  # Removes build-output/
```
